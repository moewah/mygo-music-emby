# Emby · MyGo Music 插件

在 [MyGo Music](https://github.com/egoist/mygo-music) 中浏览和播放自建 [Emby](https://emby.media/) 音乐库。

插件通过 Emby 的 REST API 连接服务器，无需改 App 代码，也无需额外程序。

## 安装

需要 MyGo Music **0.1.24 或更新版本**。

1. 打开 MyGo Music → **设置 → 插件 → + → 从文件夹安装**，选择本目录。
2. 在插件设置中填写：
   - **服务器地址**：包含协议和端口，例如 `http://192.168.1.10:8096`；也可以填 `https://emby.example.com`。部署在子路径时填完整地址，例如 `https://example.com/emby`。
   - **用户名 / 密码**：Emby 账号，点击来源选择器里的**登录**完成验证。
   - 或者填 **API 密钥**：在 Emby 后台的 **设置 → 高级 → API 密钥** 生成。API 密钥优先于用户名和密码。
3. 在来源选择器中选择 **Emby**。

修改服务器或账号后需要重新登录；正在播放的歌曲不受影响。

## 功能

- 首页：顶部是当天的**每日推荐**（40 首，显示为带日期的大卡片），下面是 20 首喜欢的歌曲（「查看全部」进入完整的喜欢歌曲页）、最近添加的 10 张专辑、10 张喜欢的专辑和 10 位喜欢的歌手，每段都可以「查看全部」。
- 每日推荐：常听歌曲、喜欢的歌曲、相似推荐（Emby InstantMix，以喜欢的专辑为种子）和未播放的歌曲各 10 首，每天生成一次，当天内不再变化。
- 浏览：侧边栏有每日推荐、常听歌曲、所有专辑、喜欢的歌曲和喜欢的专辑。「所有专辑」和首页「最近添加」的「查看全部」共用同一页，都按入库时间倒序列出全部专辑；「喜欢的歌手」从首页区块的「查看全部」进入。专辑页一次加载完整列表，不再分页。艺术家详情从歌曲、专辑、搜索结果进入，艺人页上的「关注」会把他加进首页的「喜欢的歌手」。
- 搜索：歌曲、专辑、艺术家和播放列表。
- 收藏：喜欢的歌曲、喜欢的专辑、关注艺术家；以及“我的页面”汇总。
- 播放列表：创建、重命名、删除，添加、移除和排序歌曲。
- 播放：原文件直传；播放器不支持的格式自动转成 MP3；播放后会把歌曲标记为已播放，Emby 的播放次数和最近播放保持同步。
- 歌词：播放时自动获取同步歌词，优先 [LRCLIB](https://lrclib.net)，未命中时回退 [lrcmux](https://lrcmux.dev)；结果缓存在本地，没找到的歌曲三天内不会重复请求。
- 音质：标准档请求 128 kbps，高音质档 320 kbps，无损档优先原文件。
- 界面支持简体中文和英文。

## 账号与权限

- 插件声明了访问任意网络主机的权限，因为自建 Emby 的地址不固定。
- 插件用 `X-Emby-Token` 请求头访问 API；图片和音频请求同样通过 `requestHeaders` 携带令牌，不把令牌写进 URL。
- 账号密码由 MyGo Music 明文保存在插件设置中，API 密钥和访问令牌保存在插件数据目录中。建议使用 HTTPS，并为插件单独创建一个 Emby 用户。
- API 密钥是服务器级凭据，部分用户级操作（例如修改收藏、编辑播放列表）可能被 Emby 拒绝。需要这些功能时请使用用户名和密码登录。
- 歌词查询会把歌曲名、歌手、专辑和时长发送到 `lrclib.net` 与 `api.lrcmux.dev`，不会发送账号信息；歌词结果保存在插件数据目录中，退出登录时清除。

## 开发

无需构建或安装依赖。使用 Node.js 20 或更新版本运行语法检查和测试：

```sh
npm run check
npm test
```

把目录复制或软链接到 MyGo Music 的插件目录即可联调：

```sh
ln -sfn "$PWD" "$HOME/Library/Application Support/MyGo Music/plugins/emby"
```

重启 MyGo Music 后，在 **设置 → 插件** 中启用。
